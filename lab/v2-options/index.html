REV v2: type and layout options

Pick a display typeface and a way of laying out lists that isn't a grid of cards. The switch at the top changes the display face across the whole board, so you can mix any type option with any layout. Body text stays REV Text (the Lato the approved site uses), so only the personality changes. All content below is real site copy.

Display face

Part 1 · Display typefaces

All three are open-licensed (SIL OFL) and can be self-hosted in a light subset, the same way v2 already serves its fonts. None of them is a default on generated sites, and each comes from a different corner of a race team's world.

Option 1

Carrera

Rice’s only student-built wheel-to-wheel racing team

400lbs, estimated driverless weight
1000W solar array
75+mph, simulated top speed

Anybody, extra-expanded black italic: livery lettering.

A variable typeface with a width axis. Opened up wide and slanted forward, it matches the REV mark’s italic and reads like the lettering painted on a race car. Condensed widths are there for tight spots, like phone headings, from the same file.

Best with: decal sheet, pit boards.

Option 2

Carrera

Rice’s only student-built wheel-to-wheel racing team

400lbs, estimated driverless weight
1000W solar array
75+mph, simulated top speed

Big Shoulders Display, black: pit wall and paddock signage.

A tall, condensed face drawn from Chicago’s industrial signage. It packs big words into narrow spaces, like timing screens, garage boards and grandstand numbers, and its figures are made for lap times and specs.

Best with: timing tower, pit boards.

Option 3

Carrera

Rice’s only student-built wheel-to-wheel racing team

400lbs, estimated driverless weight
1000W solar array
75+mph, simulated top speed

Martian Mono, expanded bold: the engineer’s instrument.

A monospace face with a width axis, set wide and heavy. It feels like telemetry readouts, CAD title blocks and the team’s ECU screens: the student-engineering side of REV rather than the glamour side.

Best with: wiring harness, timing tower.
